## 📸 How to Add Your Real Images

### Step 1: Gather Your Photos
Collect high-quality photos from your cafe:
- Interior shots (cozy seating areas, ambiance)
- Food & beverage photos (coffee, dishes, mocktails)
- Exterior/front view of the cafe
- Team/owner photos
- Any special moments from Instagram/Facebook

### Step 2: Save Images to Correct Folder
Place all images in: `/the-thesis-cafe/public/images/`

### Step 3: Name Files Exactly As Listed

#### Hero/Home Page Images:
```
hero-cafe-interior.jpg    → Main cafe interior (1920x1080 recommended)
hero-coffee.jpg           → Signature coffee drink close-up
cafe-ambiance-1.jpg       → Cozy seating area 1
cafe-ambiance-2.jpg       → Cozy seating area 2
```

#### Menu Images:
```
coffee-latte.jpg          → Latte with art
coffee-cappuccino.jpg     → Cappuccino
continental-pasta.jpg     → Pasta dish
italian-pizza.jpg         → Pizza
chinese-noodles.jpg       → Chinese noodles/stir fry
dessert-cake.jpg          → Cake/dessert slice
mocktail-colorful.jpg     → Colorful mocktail
```

#### About Page Images:
```
about-owner.jpg           → Owner/chef photo
about-team.jpg            → Team photo
about-journey.jpg         → Cafe story/timeline image
```

#### Contact Page Images:
```
exterior-front.jpg        → Front view of cafe
location-map.jpg          → Map showing location (optional)
```

### Step 4: Image Requirements
- **Format**: JPG or PNG
- **Quality**: High resolution but web-optimized
- **Hero Images**: Minimum 1920x1080 pixels
- **Menu/Other Images**: Minimum 800x600 pixels
- **File Size**: Keep under 500KB per image for fast loading
- **Compression**: Use tools like TinyPNG or Squoosh.app

## 🚀 After Adding Images

Once you've added all images to the `/public/images/` folder:

1. **Test locally**: `npm run dev`
2. **Build for production**: `npm run build`
3. **Deploy to Vercel**: Push to GitHub and connect to Vercel

The website will automatically use your real images instead of placeholders!

## 💡 Pro Tips

1. **Consistency**: Use similar lighting and style across all photos
2. **Authenticity**: Real photos of your actual cafe perform better than stock images
3. **Food Photography**: Natural lighting works best for food shots
4. **Ambiance**: Show customers enjoying the space (with permission)
5. **Instagram Feed**: Consider embedding your Instagram feed later using a widget
